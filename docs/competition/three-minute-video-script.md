# Sairo — Three-Minute Video Script

**Working script for a maximum three-minute submission video.** All screens show the local prepared demo. No real AI request or teammate response occurs.

| Time | Screen / transition | Narration |
|---|---|---|
| 0:00–0:25 | Open on a team chat. Highlight “Let’s have the payment feature done by Friday.” | “A short message can sound clear while leaving the most important question unanswered: what does done mean?” |
| 0:25–0:50 | Show three fixed profile cards, then the manager, engineer, and designer interpretations. | “A product manager may mean customers can use the feature. An engineer may mean the code is complete. A designer may mean the screens are approved. These are illustrative roles in our prepared scenario, not research findings.” |
| 0:50–1:15 | Open Clarity tools → Before sending. Point to owner, deadline, completion criteria, priority, and scope prompts. | “Before sending, Sairo surfaces questions each recipient may have and information the draft leaves open. The proposal is optional. The original stays available, and applying a proposal never sends it.” |
| 1:15–1:35 | Select Tailored translation. Show original next to Alex, Jamie, and Sam cards; briefly show role and knowledge labels. | “The same message is shown in the context of each person’s role, experience, and cross-discipline knowledge. Compare every version with the original before using it.” |
| 1:35–2:00 | Return to Friday payment conversation; scroll through prepared chat. | “The team continues in a conversation. In this prototype, messages stay in browser memory. The conversation and analysis are prepared examples.” |
| 2:00–2:40 | Open Thread check → Friday payment launch. Show evidence links; click each source. Then show local participant-answer simulation with different answers. | “Thread check marks this as a potential misunderstanding and links the supporting messages. That label is an estimate, not a fact. The local simulation lets a presenter try answers. Only differing explicit simulated answers show ‘Confirmed disagreement’; no answer or uncertainty stays ‘Unresolved.’ These are not actual teammate replies.” |
| 2:40–3:00 | Show an aligned response state, then return to the original message. | “Matching answers show alignment on that question. Sairo’s goal is not to decide who is right. It is to help a team make the work, scope, and completion criteria clear together.” |

**Recording note:** keep the demo-mode label visible at least once, avoid implying live model accuracy, and do not show fabricated user statistics or customer logos.
