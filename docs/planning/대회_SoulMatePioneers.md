### 4.2 최종 결선

| 기준 | 비중 | 11/20 이후 채울 것 |

| 기술 혁신성 및 완성도 | 30% | B(오해 탐지) 완성. 평가 데이터로 측정한 정확도 수치 |
| **사업성 및 성장 가능성** | **40%** | **인터뷰 결과** (몇 명에게 물었고, 몇 팀이 쓰겠다고 했는지), 가격 모델, 1인당 AI 비용 계산, Slack 마켓 등록 계획 |

## 5. 준비 계획

### 5.1 서류 마감까지 (~11/15)

| 날짜 | 개발 | 기획+디자인 |
|---|---|---|
| 11/10~11 | Slack 앱 생성, Bolt 설정, 메시지 단축키 | 신청서 목차 확정 (5.4), 대표자 자격과 증명서 확인, 구글 폼 양식 확인 |
| 11/12~13 | **기본 번역 구현**: 프로필 3명 (기획 시니어, 프론트엔드 주니어, UI 디자이너 미들), 직무별 출력 형식 프롬프트 | 영어 신청서 초안 작성, B·A 화면 시안 (Block Kit Builder) |
| 11/14 | 시연 장면 녹화 (동작 화면 1분) | 영상 대본 작성, 신청서 다듬기 |
| 11/15 | 영상 편집과 최종 확인 → **제출** | |

**구현 범위 (서류용)**
- ✅ 기본 번역: 메시지 단축키 → 세 사람에게 맞춘 번역 3개가 나오는 장면 (사내 앱이라 호출 제한 없음)
- ✅ 원문 함께 보기, ⚠️ 추측 표시 (프롬프트로 처리, 화면에 보이면 충분)
- 🎨 B(오해 탐지), A(보내기 전 점검): **화면 시안**으로 대체
- ❌ OAuth, DB, 프로필 설정 화면: 프로필은 코드에 직접 입력

### 5.2 온라인 발표까지 (~11/20)

| 할 일 | 비고 |
|---|---|
| B 오해 탐지 구현 (미리 준비한 스레드 1~2개) | 사람별 요약 → 비교 → 어긋나는 부분 표시. 확인 질문 DM은 시안으로 대체 가능 |
| (여유가 있으면) A 또는 D | D는 프로필에 언어 항목만 추가하면 되어서 비용이 적고, **글로벌 심사단**에게 잘 맞음 |
| 7분 영어 발표 자료 + 시연 | 시연이 실패할 때를 대비해 **녹화 영상을 백업으로** 준비 |
| 질의응답 대비 | 5.5의 예상 질문 |

> 1차 합격 발표가 11/19(목)이므로, **합격 여부와 상관없이 11/16부터 발표 준비를 시작**합니다.
