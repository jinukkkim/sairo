### ① AI Agents for Founders Challenge — HETIC 2026 ⭐ 가장 잘 맞음 🟡
| 항목 | 내용 |
|---|---|
| 주최 | HETIC (프랑스 웹·디지털 학교), Devpost |
| 형식 | 온라인, 전 세계 참가 가능 (일반적인 제외 국가만 제외) |
| 마감 | **2026-12-18 17:00 (파리 시간) = 12/19 01:00 (한국 시간)** |
| 심사 | 2026-12-19 ~ 2027-01-08 |
| 대상 | **대학생 2~4명 팀** |
| 주제 | 창업자의 시간을 돌려주는 AI 에이전트. **모든 에이전트에 사람이 확인하는 단계(human checkpoint)가 있어야 함** |
| 상금 | 현금 €1,000 |
| 링크 | https://ai-agents-founders-hetic-26.devpost.com/ |

**우리 아이디어와 맞는 점**
- 대상을 "스타트업 창업자"로 좁히면 됩니다. 창업자는 기획·개발·디자인·투자자·고객과 모두 대화하므로 **관점 번역**이 필요한 대표적인 사람입니다.
- 필수 조건인 "사람 확인 단계"가 B(오해 탐지)의 **객관식 확인 질문**, A(보내기 전 점검)의 **보내는 사람의 최종 확인**과 그대로 맞습니다.
- 영어로 제출하므로 D(언어 동시 번역)를 함께 보여주기 좋습니다.

**준비할 것**
- 영어 데모 영상(보통 3분 내외), 영어 설명문, GitHub 저장소
- 데모는 [개발_조사.md](./개발_조사.md) 3.1의 대회 데모 범위(기본 번역 + B)면 충분합니다. 지금부터 약 5주가 남아 있어 일정이 여유롭습니다.
- ⚠️ Devpost 페이지가 자동 접속을 막아서 세부 규칙(제출물, 심사 기준, 사용 도구 제한)을 직접 확인하지 못했습니다. **가입 전에 Rules 탭을 꼭 확인하세요.**

- 우리 핵심 기술(같은 내용을 받는 사람의 직무·숙련도에 맞춰 다시 쓰기)은 **"숙련자 → 신입 작업자 기술 전수"**, **"현장 작업자 ↔ 사무실·설계 부서 소통"**에 그대로 쓸 수 있습니다.
- 문제가 당일 공개되므로 **완성된 Slack 앱보다는 "관점 번역 엔진(프롬프트 + 프로필 구조)"을 빠르게 붙이는 능력**이 중요합니다.
- 팀이 3~4명이어야 합니다. **지금 2명이므로 1~2명을 더 모아야 합니다.** ([개발_조사.md](./개발_조사.md) 4장의 "2~4주 시험 과제"로 활용 가능)
- 상금은 작지만 KAIST·중진공 네트워크가 생기고, 기술 응용 범위가 넓다는 근거가 됩니다.
